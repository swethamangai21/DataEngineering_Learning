# Scenario 1: CSV File Ingestion

## Objective

Practise reading CSV files with and without headers, using different
delimiters, inferred schemas and explicitly defined schemas.

## Scenarios Completed

- Read a CSV file with a header.
- Read a CSV file without a header.
- Assigned column names manually using `toDF`.
- Read a pipe-delimited CSV file.
- Observed the result of using an incorrect delimiter.
- Compared inferred schema with an explicit schema.
